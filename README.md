# PROBE

### Autonomous AI-Powered Web Application Testing

> **Give it a website. Let it find what you missed.**

PROBE is an AI-powered web testing platform that autonomously explores websites, investigates suspicious behavior, reproduces issues, collects evidence, and generates structured findings.

Unlike traditional automated testing that follows predefined test cases, PROBE uses AI agents to decide **what to explore and investigate next**.

## How It Works

```text
Website
   ↓
AI observes
   ↓
Chooses an action
   ↓
Playwright executes it
   ↓
Observes result
   ↓
Investigates suspicious behavior
   ↓
Collects evidence
   ↓
Generates findings
```

## AI Agents

* **Technical AI** — Functional and technical issues
* **UX/UI AI** — Usability and interface problems
* **Chaos AI** — Unexpected and stressful interactions
* **User AI** — Realistic user behavior
* **Review AI** — Validates, correlates, and summarizes findings

## Live AI Testing

PROBE provides a live browser view where you can watch the AI:

* Navigate websites
* Move and click
* Type and scroll
* Investigate issues
* Generate findings in real time

## Tech Stack

* React + TypeScript + Vite
* Python + FastAPI
* Playwright + Chromium
* LLM API
* WebSocket
* SQLite
* Tailwind CSS

## Core Idea

> **Don't automate only the test cases humans already know. Automate the investigation of what humans haven't thought to test.**
